# Дополнение 1.1 к пятому тому

Базовый исходный код: https://github.com/MaytakRoman/multimodal-systems-engineering-vol5/tree/18463cb207c1c2ffa563f928c49691feeb066c5f

Дополнение размещается в корне той же ветки main. Базовый коммит сохраняет исходную редакцию; новые программы и review_results относятся к дополнению 1.1.

## Численные опыты

Работа выполняется из корня распакованного каталога, в отдельной среде Python 3.12.14.

```
python -m pip install -r requirements_review_base.txt
python tests.py
python run_all.py --output reproduced_base
python review_robotics.py --output reproduced_review/robotics --seed 2026
python review_industrial.py --source results/chapter11 --output reproduced_review/industrial
python review_deployment.py --output reproduced_review/full_rank_svd.json
python lot_conditions.py --source results/chapter11 --output reproduced_review/industrial/lot_conditions.json
python review_checks.py
```

Каталог для общего запуска должен быть новым: служебные `.gitkeep` исходного `results/` участвуют в побайтном сравнении старого `run_all.py`. Отдельный каталог сохраняет оригинальные файлы. Для следующего повтора выбирают другое новое имя.

## Открытые модели

Для сохранённого опыта использованы CPU-версии PyTorch 2.5.1+cpu и Transformers 4.46.3. Рекомендуется отдельная среда от исходного численного комплекта.

```
python -m pip install torch==2.5.1+cpu --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements_review_models.txt
python real_models.py
```

Веса и конфигурации загружаются из официальных репозиториев OpenAI на Hugging Face по двум фиксированным редакциям из models.json. Веса не включены в архив. Три фотографии взяты из поставки scikit-image 0.25.2. Аудио jfk.flac получено из официального теста OpenAI Whisper v20240930. Полные входы и SHA-256 находятся в review_results/open_models.

Проверка CLIP содержит три изображения и три английских запроса; Whisper — одну английскую запись. Эти результаты не являются оценкой на предметном корпусе. Время CPU не является временем камеры; p50/p95 вычислены по 40 вызовам одного визуального кодировщика после пяти прогревочных. Максимальная RSS относится к процессу с обоими загруженными кодировщиками. Аппаратные времена при повторении могут измениться.

## Численные изменения

- review_robotics.py: стенка до обеих границ, один проход, изображение RGB и две команды с неоднозначностью и уточнением.
- review_deployment.py: матрица полного ранга и ряд рангов SVD.
- review_industrial.py: 20 000 повторных выборок по партиям, неизменный визуальный порог, объединение изображения, текстового маршрута и журнала оборудования.

Результаты исходных глав остаются в results/chapter01 … results/chapter11. Результаты редакции 1.1 — в review_results. Синтетический трёхканальный тест имеет другую конечную целевую переменную, чем исходный визуальный тест; показатели сопоставляются только на одинаковом покрытии.

## Погрешность датчика момента

В исходном трёхканальном опыте момент точен по построению. `review_industrial.py`
добавляет N(0, sigma²) при sigma = 0; 0,5; 1; 2 Н·м, сохраняя эталон и те же 131 вход.
Сохраняются одна реализация по уровням sigma и средние по 1000 реализациям с seed=2028.
Это моделирование погрешности на фиксированном наборе, а не доверительный интервал
производственной генеральной совокупности. Одни и те же стандартные нормальные
выборки используются для сравнения уровней шума.

`lot_conditions.py` восстанавливает параметры партий по исходному генератору
и побайтно проверяет все 432 изображения. Выход сохраняет освещённость, шум и
контраст дефектов, а не выводит причины ошибок из одной матрицы качества.

## Проверка загруженных файлов

```
python verify_archive.py
python review_checks.py
```

`SHA256.json` охватывает исходные и добавленные файлы. `SHA256_REVIEW.json` —
файлы дополнения. Оба перечня исключают сами файлы контрольных сумм.
Аппаратные времена при повторном запуске меняются; сохранённые измерения книги
находятся в `review_results/open_models`.

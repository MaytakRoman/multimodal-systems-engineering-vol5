# 9. Мультимодальные агенты и робототехника

Исполняемый пример: [chapter09_robotics.py](../chapter09_robotics.py). Алгоритмы: [mmbook/robotics.py](../mmbook/robotics.py).

```sh
python chapter09_robotics.py --output results --seed 2026
```

Команду выполняют из корня репозитория. Результат — `results/chapter09/summary.json` и дополнительные файлы.

## 9.1. Модели «зрение — язык — действие»

Функции и точки разбора: `shortest_path и разбор command в experiment`.

Наблюдение задаётся полной сеточной картой и таблицей объектов. Команда ограниченного формата выбирает цель по её имени. План строится BFS по свободным клеткам, затем агент действует и перепланирует. Это символический пример контракта наблюдение–команда–действие, а не обученная VLA или визуальное распознавание объекта.

## 9.2. Перенос из симуляции в реальный мир

Функции и точки разбора: `simulate`.

Шум slip меняет желаемое действие на случайное соседнее. Для четырёх уровней шума выполнено по 60 эпизодов, подсчитаны успешные завершения, шаги и столкновения. Столкновение оставляет позицию неизменной. Здесь измеряется чувствительность симулятора к шуму действий; реальный робот и sim-to-real эксперимент отсутствуют.

## Сохранённые результаты

scene.json содержит карту, цели и команду; episodes_*.json — полные истории для каждого уровня slip.

Область применимости и численные значения зафиксированы в summary.json. Синтетическое происхождение данных указано явно.

## Задание для самостоятельного опыта

Уменьшите лимит шагов и сопоставьте success rate с числом столкновений. Добавьте неизвестное препятствие и обсудите, как изменится контракт полного наблюдения.

## Проверки

`python tests.py` проверяет независимые контрольные значения и граничные контракты. `python run_all.py` дополнительно проверяет повторение файлов и согласованность промышленного кейса.

# 10. Эффективность и развёртывание на устройствах

Исполняемый пример: [chapter10_deployment.py](../chapter10_deployment.py). Алгоритмы: [mmbook/deployment.py](../mmbook/deployment.py).

```sh
python chapter10_deployment.py --output results --seed 2026
```

Команду выполняют из корня репозитория. Результат — `results/chapter10/summary.json` и дополнительные файлы.

## 10.1. Сжатие мультимодальных моделей

Функции и точки разбора: `quantize_rows и low_rank`.

Матрица сжимается поканально: масштаб вычисляется по максимуму абсолютного значения строки, INT8 ограничен диапазоном [-127,127]. Для нулевой строки scale=1. Проверяется относительная ошибка выходного matmul. SVD иллюстрирует приближение матрицы низким рангом. Исходная матрица сконструирована ранга 8, поэтому малый остаток SVD не характеризует реальную большую модель.

## 10.2. Вывод на периферийных устройствах и промышленных камерах

Функции и точки разбора: `simulate_queue`.

Очередь одного обработчика ограничена capacity, включая обслуживаемый кадр. При переполнении новый кадр отбрасывается; completion учитывает занятость обработчика. p95 относится к расчётным задержкам такой очереди. Реальная камера, драйвер, NPU и INT8 kernel не запускаются; развёрнутый float matmul нужен только для оценки численной ошибки.

## Сохранённые результаты

weights_fp32.npy, weights_int8.npy и scales.npy сохраняют параметры. queue.json показывает принятые и отброшенные кадры с временами.

Область применимости и численные значения зафиксированы в summary.json. Синтетическое происхождение данных указано явно.

## Задание для самостоятельного опыта

Измените частоту кадров и service_ms. Сравните drop rate и возраст принятого кадра при разных capacity.

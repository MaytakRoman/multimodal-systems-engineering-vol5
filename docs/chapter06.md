# 6. Видео

Исполняемый пример: [chapter06_video.py](../chapter06_video.py). Алгоритмы: [mmbook/video.py](../mmbook/video.py).

```sh
python chapter06_video.py --output results --seed 2026
```

Команду выполняют из корня репозитория. Результат — `results/chapter06/summary.json` и дополнительные файлы.

## 6.1. Понимание длинного видео

Функции и точки разбора: `windows`.

Окна задаются полуоткрытыми интервалами [start, end). Они покрывают всё видео с заданным перекрытием, последнее окно может быть короче. Пример использует длительность в секундах; функция не декодирует файл и не формирует семантическое описание кадров.

## 6.2. Видеоаналитика: события, аномалии, подсчёт

Функции и точки разбора: `count_crossings и event_intervals`.

Пересечения линии считаются слева направо и максимум один раз для данного track_id. Это модель подсчёта уникальных изделий, а не суммирование всех проходов одного объекта. Интервалы тревоги короче min_frames отбрасываются. Track ID и булевы тревоги заданы во входе, поэтому ошибки реального детектора и трекера не измеряются.

## Сохранённые результаты

tracks.json содержит временные координаты; event_signal.json — покадровую активность. summary отделяет активные кадры от числа событий.

Область применимости и численные значения зафиксированы в summary.json. Синтетическое происхождение данных указано явно.

## Задание для самостоятельного опыта

Добавьте обратный проход и повторное пересечение. Измените min_frames и объясните обмен между короткими ложными тревогами и пропуском коротких событий.

## Проверки

`python tests.py` проверяет независимые контрольные значения и граничные контракты. `python run_all.py` дополнительно проверяет повторение файлов и согласованность промышленного кейса.

# Инженерная практика мультимодальных систем — том 5

Программное сопровождение пятого тома серии «Прикладной искусственный интеллект».
Авторы книги: П. А. Пылов, Р. В. Майтак, А. В. Протодьяконов.
Версия комплекта: 1.0.0 от 14 октября 2026 года.

Комплект содержит исполняемые расчётные эксперименты по всем 11 главам:
зрение, документы, речь, видео, генерация, агенты, сжатие и производственный кейс.
Они показывают инженерные операции, метрики и контракты на синтетических данных.
Предобученные большие модели и внешние сервисы в этих опытах не используются.

## Быстрый запуск

Проверено на Linux, Python 3.12.14, NumPy 2.3.5. Команды выполняются из корня
распакованного комплекта. После установки NumPy интернет и GPU не требуются.

```sh
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell вместо предыдущей строки:
# .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run_all.py
```

На Linux/macOS интерпретатор может называться `python3`.
Windows и macOS в данной редакции не проверялись.

`run_all.py` запускает 11 примеров, арифметические проверки и тесты в отдельных
процессах, проверяет согласованность кейса, а затем повторяет вычисления в
временном каталоге и сравнивает байты всех результатов. Несовпадение приводит
к ошибке. Основной seed — 2026, генератор — NumPy PCG64.

Для отдельного опыта, не затрагивающего поставленные результаты:

```sh
python run_all.py --output rerun_results --seed 2026
python chapter05_speech.py --output my_speech_results
python reference_multimodal.py --output my_factory_results --seed 27
python tests.py
python verify_archive.py
```

При изменении seed ожидаемые метрики меняются. Порог дефектоскопии подбирается
заново по validation. Значение test не участвует в подборе.
Для проверки точного повторения используйте чистый каталог вывода.
`verify_archive.py` проверяет поставленную редакцию до её изменения. Обычный
запуск обновляет результаты и журналы; для сохранения исходных контрольных
сумм используйте `--output rerun_results`.

## Воспроизведённый опыт

Все 11 примеров выполнены; тесты и арифметические проверки пройдены.
Повторный запуск побайтно воспроизвёл 920 файлов результатов на проверенной среде.
Полные сведения находятся в `execution_report.json`, вывод тестов — в
`execution_logs/tests.txt`. Это проверка воспроизводимости данной реализации
на данной среде; другой BLAS или версия NumPy может изменить последние разряды.

В кейсе главы 11 созданы 36 партий по 12 изделий: 216 изображений train,
72 validation и 144 test. Партии не пересекаются. На validation выбран порог
0.2051398122470898. На test: TP=37, FP=28, FN=11, TN=68; F1≈0.6549.
Разница с validation F1≈0.9020 показывает, почему недостаточно отчёта по
выборке, на которой выбирался порог. Данные и все предсказания включены в комплект.

## Границы результатов

Это собственные учебные реализации, а не исходники CLIP, ViT, VLM, Whisper,
диффузионной нейросети или VLA. Контрастивная потеря вычисляется на синтетических
векторах; OCR-боксы и детекции заданы входными fixtures. Сегментация главы 2
использует яркостный порог. Генерация главы 7 работает с аналитическим полем
в 2D; главы 8 — с процедурными медиа. Кейс главы 11 использует три ручных
признака и логистическую регрессию. Правило СИЗ получает готовые логические
признаки и не распознаёт работников по изображению.

Задержки очереди в главе 10 моделируются, а не измеряются на промышленной
камере. INT8-матрица разворачивается перед NumPy matmul, поэтому ускорение
аппаратного INT8 здесь не доказывается. Байтовые объёмы относятся к payload,
не ко всему контейнеру NPY. Реальное качество нейросетевых моделей, безопасность
предприятия и экономический эффект по этим данным не оцениваются.

Примеры дополняют темы книги; они не заявлены как воспроизведение каждой
числовой таблицы рукописи. Для будущих глав код уже подготовлен; текст и
практикумы этих глав будут привязаны к соответствующим программам при написании.

## Публикация и ссылки

В GitHub загрузите содержимое папки `multimodal-systems-engineering-vol5`,
сохранив вложенные каталоги. В корне репозитория должны оказаться README.md,
run_all.py и mmbook/, а не ещё один промежуточный каталог с именем архива.
Текст книги в программный репозиторий не включён.

После публикации можно получить полные ссылки для вставки:

```sh
python make_book_links.py --repo https://github.com/OWNER/REPOSITORY
```

Команда создаёт `links_for_manuscript.json` и `links_for_manuscript.md`.
Для закрепления конкретной редакции добавьте `--ref COMMIT_SHA` вместо
плавающей ветки main. Архив уже содержит относительные ссылки, действующие
при любом имени репозитория.

Код распространяется по MIT (см. LICENSE); NumPy имеет собственную лицензию.
Справочные API: [SVD](https://numpy.org/doc/2.3/reference/generated/numpy.linalg.svd.html),
[PCG64](https://numpy.org/doc/2.3/reference/random/bit_generators/pcg64.html).
